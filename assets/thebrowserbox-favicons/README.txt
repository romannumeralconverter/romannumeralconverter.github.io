TheBrowserBox favicon pack

1. Copy the image files and site.webmanifest to your website root.
2. Paste favicon-links.html into your HTML head.
3. Edit the manifest site names and paths for your own site. For subfolder hosting, update every root-relative path in the HTML and manifest.
4. Use a solid background if your platform does not support transparent home-screen icons. These are ordinary icons, not maskable icons.
5. Clear your favicon cache or test in a fresh browser session if an old icon appears.

ICO contains 16/32/48-pixel uncompressed 32-bit bitmap frames and a 256-pixel PNG frame. PNG files are raster images; upscaling cannot restore missing detail. The preview and export use the same crop, padding and background settings. Original metadata is not preserved.

These icon files alone do not make a website an installable PWA.
